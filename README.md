# Иван Макогон — архитектор

Портфолио-лендинг. Живая версия: **https://makvanser.github.io/portfolio/**

Архив из 12 работ — жилые комплексы, медицинские и общественные здания, конкурсы
и визуализации для бюро. Запись раскрывается прямо в строке хронологии: сначала
описание проекта, затем мозаика материалов, разбитая по сериям съёмки.

## Устройство

Одна статическая страница без сборки и зависимостей.

```
index.html        разметка, стили и скрипт целиком
assets/img/       104 кадра в WebP, включая портрет
.nojekyll         GitHub Pages отдаёт файлы как есть
```

Данные проектов лежат в самом `index.html`, в массиве `PROJECTS`. У каждого кадра
есть тип (`render`, `plan`, `poster`, `video`), подпись и серия — по ней страница
строит заголовки внутри мозаики.

## Локальный просмотр

```bash
python3 -m http.server 8080
```

## Шрифты

Onest — крупная типографика и заголовки, Familjen Grotesk — текст,
IBM Plex Mono — служебные подписи. Подключены с Google Fonts.
